**Deviations (no visible change):**
- Windows sit in one `.os-wlayer` element (z-index 5, the source's window layer) and stack with an inline z-index instead of being moved in the DOM. - Bridged apps hide the legacy solo window's own title bar inside the frame (the OS window already has one). Pointer input inside the frame is forwarded so the window comes forward.
